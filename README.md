# Anthony De Los Santos — Author Platform

A responsive, static author-platform website for the course milestone. It includes a landing page, biography page, works-in-progress page, and social links.

## Open it locally

Double-click `index.html` or open the folder in a browser to preview it.

## Publish to GitHub Pages

Because this repository is named `pentopage.github.io`, GitHub Pages can publish it automatically as a user site.

1. Go to the repository on GitHub.
2. Open **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

GitHub will generate a public URL like:
`https://pentopage.github.io/`

## Helpful notes

- Replace the placeholder social links in `index.html` with your real Instagram/TikTok/etc. URLs when you create them.
- Add real content to `bio.html` and `works.html` later for the final version.
